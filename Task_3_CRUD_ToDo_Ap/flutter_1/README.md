# StudyCards — Modern Flashcard & Learning App

StudyCards is a modern mobile flashcard application built with Flutter, Provider, and SQLite.

## Features
- **Clean Architecture**: Layered provider pattern with repository abstraction.
- **Dynamic 3D Flip Cards**: Flip animation built via Matrix4 transformations.
- **Full Offline Storage**: Local persistence using SQLite (`sqflite`).
- **Progress Tracking**: Charts and study performance metrics.

## Getting Started
1. Run `flutter pub get`
2. Run `flutter run`
